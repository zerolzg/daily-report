# 市场复盘页每日存档最新快照，并以聚合文件供趋势视图

市场复盘页要提供 7 天/30 天趋势，而上游 API 只返回当日快照——今天不存的字段事后无法补回，存档格式因此难以逆转。我们决定：每次抓取把 4 份快照写入 `data/history/YYYY-MM-DD/`（当日重复运行覆盖当天，保证"当日最新快照"语义），保留 90 天；同时生成聚合文件 `data/history/trends.json`（指数收盘/涨跌序列 + 个股 7/30 天累计涨跌），前端一次请求渲染全部趋势视图。

## Considered Options

- 前端逐日拉取原始存档自行计算：请求数随天数线性增长，移动端不可接受。
- 只存聚合、不存原始快照：丢失未来新增视图的可能性，违背"存档即原始记录"。

## Consequences

- 新增字段必须从今天开始存档才会出现在未来趋势里。
- 存档与页面同走 docs/ 推送链路，Pages 仓库体积按天缓慢增长（90 天上限，约 4MB）。
